Learning Management System (LMS) - OOPs Java Project

This project is a simple Learning Management System (LMS) developed using Java and Object-Oriented Programming (OOPs) concepts. The system helps manage students, courses, and instructors in an organized way.

Features
Add and manage students
Add and manage courses
Assign instructors to courses
Enroll students in courses
Display course and student details


OOP Concepts Used
Class & Object – Represent students, courses, and instructors
Encapsulation – Protect data using getters and setters
Inheritance – Reuse common properties and methods
Polymorphism – Method overriding for flexibility
Abstraction – Simplify complex implementation details


Technologies Used
Java
OOP Principles
Console-based Interface
